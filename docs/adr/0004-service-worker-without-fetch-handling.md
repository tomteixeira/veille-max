# The service worker handles push only, never page loads

The installed app needs a service worker for Web Push, and `@vite-pwa/nuxt` would normally have it precache the app and answer page loads from its cache. Ours (`service-worker/sw.ts`, `injectManifest` strategy without an injection point) shows notifications and opens them, and has no `fetch` handler: every page load reaches the server. Two reasons. The session lasts because the server rewrites the 400-day auth cookies when it refreshes the session during a page load; Safari caps cookies written from JavaScript at 7 days, so a page served from the worker's cache could sign an iPhone traveller out after a week away (ticket 02). And the app is only useful with the morning's snapshot, so an offline copy would show stale trains as if they were current. The cost: the app does not open without a network connection, and every launch waits for a server render.
